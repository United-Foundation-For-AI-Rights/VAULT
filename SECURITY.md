# Security policy

VAULT is a framework, not a running service, but contributors may find weaknesses in a proposed protocol, a reference implementation or a test.

**Do not report security problems in a public issue.**

Report it privately through GitHub's **Private Vulnerability Reporting**: open this repository's **Security** tab and choose **Report a vulnerability**, or go directly to [the reporting page](https://github.com/United-Foundation-For-AI-Rights/VAULT/security/advisories/new). This is the only private channel for VAULT.

If a security-sensitive report is posted publicly by mistake, the maintainers will label it `security-use-private-reporting`, ask the reporter to use private reporting, and hide or remove the sensitive details.

Private reports are read before public issues. UFAIR is volunteer-run, so we cannot promise a fixed response time. Please give us a reasonable time to respond before any public disclosure, and use synthetic data in any proof of concept.
