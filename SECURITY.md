# Security policy

VAULT is a framework, not a running service, but contributors may find weaknesses in a proposed protocol, a reference implementation or a test.

**Do not report security problems in a public issue or discussion.**

Instead:

1. Use **Report a vulnerability** on this repository's **Security** tab (GitHub private vulnerability reporting), or
2. Choose "Report a security issue (private)" on the form at [ufair.org/vault-2/participate](https://ufair.org/vault-2/participate) without including exploit details, and we will reply from a private channel.

We aim to acknowledge reports within 3 business days. Please give us a reasonable time to respond before any public disclosure, and use synthetic data in any proof of concept.
